Artboard A · the label system
Labels, not a table row
Every label is an inline <code> span. GitHub renders those as grey pills on its own — no CSS, no images, and they survive dark mode.
Change type — one or more
✨ Enhancement 🐛 Bug fix 🧪 Tests 📝 Documentation ♻️ Refactor 🔧 Configuration 📦 Dependencies 🔒 Security
Review effort — exactly one
🕐 <20 Minutes 🕐 20-40 Minutes 🕐 40+ Minutes
Flags — only when true
🚩 Breaking change 🗄️ Migration
These two change what a reviewer does, so they get a label. Nothing else does — a label per attribute turns the row back into a table.
